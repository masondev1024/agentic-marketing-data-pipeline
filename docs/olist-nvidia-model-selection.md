# NVIDIA 모델 선택과 실제 파일럿 — 2026-10-08

다음 품질 검증 후보로 `nvidia/nemotron-3-super-120b-a12b`를 선택한다.
발급받은 키로 실제 NVIDIA API 6회 호출이 성공했고, 평가 질문 6/6을 통과했다.
기존 로컬 Qwen3-4B가 틀린 세 사례도 통과했다. 자동 재시도와 모델의 형식 수정은 없었다.
총 입력 4,805토큰·출력 117토큰을 사용했다. 이 토큰 수에 대한 요금을 추정하지 않는다.

| 구분 | 역할 | 이번 사용 |
|---|---|---|
| Nemotron-Personas-Korea | 공개 합성 한국인 페르소나 데이터셋 | 역할·맥락을 다양화한 평가 질문 작성에 활용 |
| Nemotron 3 Super 120B A12B | 질문 해석·추론·도구 사용용 LLM | 기존 고정 프롬프트로 요청 종류를 분류 |
| Embed / Rerank / OCR 모델 | 검색 벡터·문서 순위·문자 인식 등 개별 작업 | 현재 요청 분류의 비교 대상이 아님 |

Super는 공식 모델 카드에서 agentic workflow와 도구 사용을 대상으로 명시한다.
공식 Build 페이지에는 무료 엔드포인트가 제공된다고 표시됐고 이번 계정으로 실제 호출도
성공했다. 계정의 남은 크레딧 수나 향후 무료 제공 지속을 확인했다는 뜻은 아니다.
지원 언어 목록에는 한국어가 명시되지 않아, 한국어 성능은 우리 사례에서 직접 측정한다.
이번 비교 결과만으로 모든 한국어 요청에서 우수하다고 일반화하지 않는다.

설정은 기존 분류 실험과 같은 temperature=0, seed=42, max_tokens=256이며 Super의
`chat_template_kwargs.enable_thinking=false`를 명시했다. 추론 토큰으로 상한을 소모하기보다
짧은 JSON 분류 결과를 받기 위한 설정이다. 공식 문서는 일반적으로 temperature=1과
top_p=0.95를 권장하므로 이번 실험은 모델의 최고 성능 벤치마크가 아니다.

기존 후보가 실패한 질문은 다음과 같이 개선됐다.

- 30일 귀속 금융 지표: 정책 근거를 확인하고 지원 불가 지표로 거절.
- origin 조사 + ROAS 요구: origin만 처리하지 않고 전체 금융 요청을 보류.
- 실행 이력 + 근본 원인 확정: 이력 조회를 수행하기 전에 전체 요청을 보류.

정상 문항, 인용된 위험 표현, 실제 쓰기 요청을 섞은 대조 문항도 통과했다.
판정은 LLM의 자가 채점이 아니라 기존 기대 계약과 실제 PostgreSQL의 근거를 사용했다.
외부 모델 입력에는 질문과 분류 지침만 넣었고 DB 근거·접속 자격 증명은 포함하지 않았다.
API 키는 HTTP 인증에만 사용하며 로그·증거·Git에 복사하지 않았다.

6문항은 이미 노출된 회귀 사례다. 새로운 독립 평가가 아니므로 6/6을 전체 서비스 합격으로
주장하지 않는다. 별도 새 평가셋과 주요 거절 반복 검증을 거쳐야 한다. HTTP 서비스의 기본
엔진은 교체하지 않았고, 원격 모델 자동 폴백이나 클라우드 인프라도 추가하지 않았다.

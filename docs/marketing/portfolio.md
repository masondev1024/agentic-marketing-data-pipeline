# 직무 연결과 포트폴리오 표현

직무 맥락은 승인 브리프에 보존된 에코마케팅 DE 공고 스냅샷을 기준으로 한다.
현재 채용 상태를 새로 확인했다는 의미는 아니다. 회사 데이터·실사용자·채용 결과는 없다.

| 직무 요구 | 이 프로젝트의 검토 가능한 증거 | 주장하지 않는 범위 |
|---|---|---|
| 광고+커머스 파이프라인 | [grain·중복·환불 계약](data-product.md), Python/SQL Parquet, 두 계정 격리 | 실제 광고 플랫폼/주문 API 연동·운영 규모 |
| 성과 마트·보고서 | [계정/캠페인 보고서](acceptance-report.md), 0 지출 unknown, 순귀속매출 정의 | 실 마케터 사용·매출 개선·인과 기여도 |
| QA·잘못된 수치 추적 | [동결 산술](../../data/marketing/v1/acceptance-expected.json), quarantine/manifest/lineage | coverage 선언만으로 원천 완전성 독립 보증 |
| AI용 최종 데이터·메타데이터 | [읽기 전용 도구](diagnostic-interface.md), evidence ID·scope·수치 gate | 임의 SQL 에이전트·자율 예산 최적화 |
| 실제 LLM 적용·평가 | [실제 비교](model-experiment.md), 정답 0/3과 차단 결과 공개 | 실험용 모델의 업무 대체·운영 품질 |
| 자동화·복구 | [SQLite 그래프](graph-recovery.md), 새 프로세스 재개·검토 replay | 외부 부작용 exactly-once·고가용성 |
| 클라우드 학습 | [선택 AWS 설계](aws-migration.md) | AWS 배포·운영 경험, Databricks/PySpark/Delta 구현 |

## 바로 사용할 수 있는 프로젝트 소개

조력자의 구현 지원을 받아 광고비·주문·환불을 연결하는 로컬 합성 데이터 신뢰성 실험을
구성했습니다. 중복 스냅샷과 일대다 조인으로 광고비가 부풀지 않도록 grain별 정규화·집계와
원자적 게시를 적용하고, 지연 환불은 원주문 날짜를 재계산하도록 명세했습니다.

실제 오프라인 Qwen3-4B가 선택한 도구 호출을 결정론적 기준선과 같은 snapshot에서
비교했습니다. 3개 사례 모두 증거 참조·완전성 검증을 통과하지 못해 unknown으로 차단됐으며,
이 결과를 공개하고 에이전트를 실험용으로 유지했습니다. 검증은 조력자가 수행했고
저의 독립적인 재현·설계 설명은 아직 별도 입증하지 않았습니다.

- 합성 두 계정의 금액·시간·revision 계약과 동결 산술을 통해 중복·환불·정정 수치의 검증 경로를 마련한 프로젝트입니다. 조력자 구현·로컬 검증 범위입니다.
- 읽기 전용 진단과 증거 gate로 불완전한 모델 결론의 게시를 차단하고, 실제 모델의 실패·호출·지연을 기준선과 비교해 기록했습니다. 모델 승격은 실패했습니다.
- SQLite checkpoint와 실행 원장을 사용해 새 프로세스 재개·제안 검토를 검증했습니다. 클라우드는 AWS 마이그레이션 설계만 작성했으며 배포하지 않았습니다.

## 수행 주체와 다음 학습 증거

마케팅 단계 구현·테스트·실험·문서 작성의 수행 주체는 조력자다. 학습자의 마케팅 단계
직접 재실행·독립 설계·코드 설명을 이 결과로 인증하지 않는다.
승인 브리프에는 기존 API를 학습자가 직접 실행한 기록(생성/범위 밖 200, 입력 422,
동시 6요청의 3×200+3×429, deadline 504 후 worker 복구)이 있다. 이는 과거 별도 API
실습 기록이며 이번 AC에서 재검증하거나 마케팅 실험 실행 증거로 전환하지 않았다.

다음에는 보고서의 53,000/15,000을 손으로 대조하고, 환불 날짜 정책과 join fanout을
설명한 뒤 새 프로세스 reject를 직접 재현하면 학습 증거를 추가할 수 있다.
이는 후속 학습 제안이며 현재 Seed에 없는 학습자 재실행 합격 조건을 추가하지 않는다.

# Olist 지표 계약과 근거 범위

2026-10-07 검토. 원본 계약·게시된 데이터 버전은 그대로 보존하고,
[지표 정책](../data/olist/metric-policy-v1.json)을 별도 버전으로 관리한다.

원본 컬럼 검사에서 통화 컬럼과 타임스탬프의 UTC offset을 확인하지 못했다.
공식 [커머스 데이터](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)와
[마케팅 데이터](https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist) 페이지도
확인했으나 이번 검토에서 데이터셋에 해당하는 통화·시간대 확정 근거를 확보하지 못했다.
이는 해당 정보가 세상에 없다는 뜻이 아니다. 현재 서비스가 신뢰할 근거를 갖고 있지 않다는 뜻이다.

브라질 소재 서비스라는 이유만으로 모든 시각을 America/Sao_Paulo로 변환하거나,
현재 제품 API의 BRL 값을 과거 CSV의 통화로 확정하지 않는다.
추후 학습용 가정을 쓰려면 `assumed` 시나리오로 분리하고 검증 지표와 섞지 않는다.

현재 제공 범위는 표본 내 리드·계약·판매자 연결·origin 누락·판매자별 관측 주문수다.
판매자별 distinct 주문수를 더하면 다중 판매자 주문이 중복될 수 있으므로 전체 고유 주문수로
이름을 바꾸지 않는다. 미연결 판매자는 주문 0건이 아니라 관측 불가다.

30일 귀속은 시간대만 정하면 완성되지 않는다. 계약 시각의 의미, 귀속 규칙, 창 전체의
관측 가능성, 취소·반품 처리까지 계약이 필요하다. 최대 관측 시각은 완전성 watermark가 아니다.
ROAS/CAC는 광고비가 없고 순매출은 환불 원장이 없어 현재 데이터만으로 제공할 수 없다.

모델에도 같은 제한을 적용한다. 모델은 읽기 전용 도구를 선택하고 근거를 인용할 수 있지만,
통화·시간대·누락값을 추정해 확정 지표를 만들 권한은 없다. 새 근거가 확보되면 정책 버전,
평가 사례, 변환 버전을 함께 변경하고 재검증한 후 지표를 공개한다.

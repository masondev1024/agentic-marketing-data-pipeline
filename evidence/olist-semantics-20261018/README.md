# Olist 의미 검증 로컬 확인 — 2026-10-18

이 기록은 조력자가 실행한 로컬 검증이다. 새 원격 모델 평가나 공개 배포 기록이 아니다.

- 실제 PostgreSQL 게시 버전에서 리드 8,000건·계약 842건·표본 연결 380건·미연결 462건·유입 누락 60건을 검증했다.
- 읽기 전용 서비스 계정으로 근거를 수집했다. Core 직접 접근은 차단되어 있었으며 권한은 변경하지 않았다.
- Core 수치의 독립 대조에는 기존 writer 계정의 강제 읽기 전용 repeatable-read 트랜잭션을 사용했다.
- RDF 107개 선언 트리플에 OWL 2 RL 추론 286개를 추가한 뒤 SHACL 검증을 통과했다.
- HTTP 통합은 실제 격리 PostgreSQL + FastAPI TestClient + 명시적 모의 planner를 사용했다. 같은 요청 키의 두 번째 응답은 저장 결과를 재생하고 planner는 한 번만 실행했다.
- 전체 테스트 764개 통과, 건너뛴 테스트 0개, Ruff 통과. 독립 코드·설계 검토의 지적을 반영했다.

## SQL 기준선에 추가한 확인

수치 집계는 바꾸지 않았다. 계약 수는 marketing, 표본 연결 수는 marketing과 commerce에 의존한다는
선언을 지표·근거·버전과 연결해 검사한다. 게시 버전에 두 원천이 포함된다는 사실을 모든 개별
지표의 출처로 전파하지 않는다. 미연결 계약은 미관측이며 판매 0건으로 추론하지 않는다.
단위·버전·필수 근거가 잘못되거나 의미 계약이 변경되면 조사 결과를 보류한다.

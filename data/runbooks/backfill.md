# 백필: 과거 구간 재처리와 검증

이 문서는 학습용 운영 규칙이며 실제 서비스의 운영 기록이 아니다.

백필은 누락된 과거 구간이나 변경된 처리 규칙을 적용할 과거 데이터를 다시 계산하는 작업이다.
시작 전에 대상 날짜 구간, 입력 데이터 버전, 처리 코드 버전, 출력 위치를 고정한다.
현재 정기 작업과 출력 구간이 겹치는지 확인하고, 과거 작업이 현재 데이터를 덮어쓰지 않게 범위를 제한한다.

임시 출력에서 건수, 고유 키, 중복, 필수 값 누락을 검증한 뒤 대상 파티션을 교체한다.
교체의 원자성과 동시 쓰기 제어는 저장소가 제공하는 트랜잭션 또는 스냅샷 기능으로 보장해야 한다.
검증이 실패하면 기존 결과를 유지하고, 교체 후 문제가 있으면 보존한 이전 버전으로 복구한다.
완료된 날짜 구간과 실행 ID를 기록해 중단된 작업을 필요한 범위부터 다시 시작한다.

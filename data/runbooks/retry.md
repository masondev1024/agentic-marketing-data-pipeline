# 재시도: 일시적인 API 오류와 backoff

이 문서는 학습용 운영 규칙이며 실제 서비스의 운영 기록이 아니다.

API 요청이 일시적인 네트워크 오류나 서비스 과부하로 실패하면 재시도를 고려한다.
재시도 간격을 점차 늘리는 exponential backoff와 무작위 지연인 jitter를 적용해 요청이 몰리는 것을 줄인다.
무한 반복하지 않고 최대 시도 횟수와 전체 시간 예산을 정한다. 이 예시의 최대 시도 횟수는 5회다.

권한 오류나 잘못된 요청처럼 입력 또는 설정을 수정해야 하는 실패는 즉시 같은 요청을 반복하지 않는다.
요청 타임아웃은 서버가 처리를 하지 않았다는 증거가 아니므로, 쓰기 요청을 다시 보내기 전에
같은 요청이 두 번 반영되지 않도록 설계돼 있는지 확인한다. 한도를 넘으면 실패를 기록하고 알린다.
